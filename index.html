Code

I build and maintain open source tools for quantitative finance, mostly in Julia — spanning empirical research data and high-performance market-data infrastructure:

  • FamaFrenchData.jl Pull data directly from the Ken French Data Library
  • NonparametricRegression.jl Local constant and local linear kernel regression
  • DatabentoBinaryEncoding.jl Read and write Databento Binary Encoding (DBN) for high-performance market data
  • DatabentoAPI.jl Julia client for the Databento Historical (HTTP) and Live (TCP) market-data APIs
  • duckdb-dbn DuckDB extension (C++) for reading Databento Binary Encoding (DBN) files
